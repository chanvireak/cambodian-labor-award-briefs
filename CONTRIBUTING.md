# Contributing

Corrections are the point of publishing this. If a brief misstates an award, please open an issue with:

1. the document id (the filename, e.g. `140123`),
2. the paragraph number in the brief's citation scheme (or the sentence you dispute),
3. what the award actually says, with the paragraph of the award that says it.

If you can, cite the award number and date as well; the underlying awards are public documents of the
Arbitration Council of Cambodia and are not reproduced in this repository.

What is in scope:

- factual errors (wrong party, wrong outcome, wrong amount, wrong date)
- a ratio attributed to a paragraph that does not state it
- privacy failures (an individual named who should be an initial)
- OCR defects that the brief did not disclose

What is out of scope: disagreement with the panel's reasoning. These briefs report what the panel decided,
not whether it was right.

Pull requests that change many briefs at once are hard to review; please file an issue first.
